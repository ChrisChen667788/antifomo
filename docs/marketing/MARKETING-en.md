# Anti-FOMO English Marketing Copy

## One line

Anti-FOMO turns noisy web, WeChat, and local material into evidence-backed decisions, discussable architecture, and bounded next actions.

## Short launch copy

Most information tools stop at save, search, or summarize. Anti-FOMO connects WeChat/web intake, source health, evidence-backed research, version comparison, architecture readiness, human review, and action cards in one local-first workflow. It is an inspectable open-source demo: local results are not presented as production SLAs or customer acceptance.

## X / community post

Too many saved links, not enough decisions? Anti-FOMO connects `Collect → Research → Compare → Focus → Act`. Sources enter a recoverable queue, freshness and evidence gaps stay visible, and a reviewed report can become an architecture blueprint, customer questions, and a bounded action card. Open source, local-first, evidence-gated. Issues and PRs welcome.

## Three working moments

These are intended user scenarios, not customer testimonials. Use public examples or labeled demo material on screen.

| Opening | Show | Closing |
| --- | --- | --- |
| Tomorrow's customer meeting. The sources are still scattered across saved links. | Intake, failed sources, duplicates, a scoped research question. | Bring the material together, then make the questions clear. |
| A colleague asks which version supports that conclusion. | Report references and a version comparison. | Start the discussion with evidence. |
| The report is finished. The solution meeting still needs a next step. | Architecture options, dependencies, risks and validation questions. | Bring assumptions, sources and a next step to the meeting. |

## Commercial value

Anti-FOMO aims to reduce source hunting, repeated checks and research handoff work for consulting and solution teams. A scoped pilot should compare the existing workflow with the product on the same public-material dataset, measuring preparation time, source coverage and rework. Savings remain a hypothesis until measured.

## A concrete feedback invitation

Try one public scenario from source intake to solution questions. If a citation breaks, a retry fails to recover, or a suggested action is unhelpful, open an issue with a sanitized input, steps, expected result and actual result. Connector, evaluation, interface and documentation PRs are welcome.
