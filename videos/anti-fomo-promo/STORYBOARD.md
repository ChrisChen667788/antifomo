# Anti-FOMO Promo Storyboard

Use the same visual language as `docs/assets/antifomo-signal-loop.svg`: mineral white, navy ink, one petrol-teal accent, hairline connectors, deliberate pauses at HOLD and review.

1. Hook — noisy web/WeChat/file fragments; no fake metric.
2. Value — source health and recoverable queue.
3. Mechanism — evidence lens: source, version, digest, freshness.
4. Mechanism — compare and architecture readiness.
5. Scope — read-only proposal, human review, fail-closed boundary.
6. Proof — actual route/screenshot/monitor receipt with source mode.
7. CTA — Quick Start, Issue, PR and current product status.

Every timed element must have deterministic start/duration/track metadata when rendered with HyperFrames. The current checked-in SVG is the lightweight preview asset; a full MP4/GIF capture is a separate evidence artifact and must carry its own manifest.
