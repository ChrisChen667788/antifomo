# 2.10.9–2.11.8 控制面开发收口

本轮把既有路线剩余的 9 个切片（`2.10.9`、`2.11.0`–`2.11.7`）和新增的第十个切片 `2.11.8` 纳入同一条可追溯控制面。代码、接口、界面和测试完成只表示本地开发交付，不能替代供应商复核、真实设备、客户验收、独立审计或生产授权。

## 版本交付

| 版本 | 本地开发交付 | 证据边界 |
| --- | --- | --- |
| 2.10.9 | `skill_inventory` 技能/模型/来源/摘要/风险台账，签名和评测状态显式记录 | 未安装、未运行、未授权；签名和独立评测仍未验证 |
| 2.11.0 | 执行提案、allowlist、预算、幂等、显式 dry-run 回执 | dry-run 永远无外部副作用，没有具名执行批准 |
| 2.11.1 | 隔离回放、失败码和内存快照回滚演练 | `external_rollback_verified=false`，不代表外部服务可回滚 |
| 2.11.2 | 30 样本门槛、p50/p95、错误率、成本和匹配基线 | 提交测量未独立核验，不证明生产 SLA、shadow 或漂移 |
| 2.11.3 | 响应式证据摘要，区分桌面浏览器、移动 CSS 视口和 Office 页 | 移动视口不是真机，截图不等于人工视觉验收或性能基准 |
| 2.11.4 | Agent 来源刷新状态和过期复核信号 | 当前研究日期/来源已过期，厂商主张仍是 `vendor_claim_unverified` |
| 2.11.5 | 授权、去标识、qrels/盲评字段和最新工件 revision fencing | 身份、同意和客户验收保持自述/未验证，支持 synthetic fixture |
| 2.11.6 | 每周来源监测、并发抓取、JSON/Markdown artifact、人工复核 Issue | 不自动更新路线图、代码、结论或发布状态；当前来源需刷新 |
| 2.11.7 | 聚合 iteration、operation、release-readiness 和可选 artifact bridge 的交接索引 | `independent_audit_status=not_performed`，交接不等于审计通过 |
| 2.11.8 | 当前证据索引摘要、续期/撤销/HOLD 事件、过期阻断和 `baseline_hybrid` 回退声明 | append-only；不覆盖历史证据、不修改 release-readiness、不授权生产 |

## 主要接口

- `POST /api/product-strategy/operations/skills`
- `POST /api/product-strategy/operations/dry-runs`
- `POST /api/product-strategy/operations/rollback-rehearsals`
- `POST /api/product-strategy/operations/gate-reviews`
- `GET /api/product-strategy/operations/audit-handoff`
- `GET /api/product-strategy/responsive-evidence`
- `GET /api/product-strategy/agent-landscape/refresh-status`

所有操作证据按版本写入 immutable evidence 表，响应中保留 `can_auto_execute=false`、`can_auto_approve_release=false`、`production_status=not_authorized` 和 `acceptance_status=hold`。交接索引只读聚合现有记录；没有 artifact key 时明确列出 `artifact_key_missing`。

## 验证

- 后端聚焦测试覆盖技能台账、dry-run、回放/回滚、性能、反馈 fencing、来源时效、响应式摘要、交接索引和 16 条路线初始化。
- 前端工作台新增技能、dry-run、回滚和证据门禁表单，并提供操作审计包与独立审计交接索引下载。
- 竞品监测改为并发抓取，保持注册表顺序和摘要确定性，避免逐来源串行超时。

本地验证通过后，外部证据仍按 release-readiness 保持 `blocked`；生产默认继续为 `baseline_hybrid`。
