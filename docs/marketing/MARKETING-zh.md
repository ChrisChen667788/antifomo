# Anti-FOMO 中文营销文案

## 一句话

Anti-FOMO 把网页、微信和本地资料里的噪声，变成有证据的判断、可讨论的方案和下一步动作。

## 140 字

信息工具常停在收藏、搜索或摘要。Anti-FOMO 把微信/网页采集、来源健康、证据检索、版本对比、架构蓝图、人工审阅和行动卡接成一条本地优先工作流：先看什么值得相信，再决定下一步怎么做。它是可检查的开源 Demo，不把本地结果冒充生产 SLA 或客户验收。

## X / 社区贴

收藏越来越多，判断却没有更快？Anti-FOMO 把 `Collect → Research → Compare → Focus → Act` 接起来：微信/网页信号进入可恢复队列，来源新鲜度和证据缺口被标出来，研报可以继续变成架构蓝图、客户问题和行动卡。开源、本地优先、证据门禁，欢迎用 Issue/PR 一起补齐真实场景。
