# Anti-FOMO 中文营销文案

## 一句话

Anti-FOMO 把网页、微信和本地资料里的噪声，变成有证据的判断、可讨论的方案和下一步动作。

## 140 字

信息工具常停在收藏、搜索或摘要。Anti-FOMO 把微信/网页采集、来源健康、证据检索、版本对比、架构蓝图、人工审阅和行动卡接成一条本地优先工作流：先看什么值得相信，再决定下一步怎么做。它是可检查的开源 Demo，不把本地结果冒充生产 SLA 或客户验收。

## X / 社区贴

收藏越来越多，判断却没有更快？Anti-FOMO 把 `Collect → Research → Compare → Focus → Act` 接起来：微信/网页信号进入可恢复队列，来源新鲜度和证据缺口被标出来，研报可以继续变成架构蓝图、客户问题和行动卡。开源、本地优先、证据门禁，欢迎用 Issue/PR 一起补齐真实场景。

## 三个可以开场的工作瞬间

这些是目标用户场景，不是客户证言；画面使用公开样例或明确标注的 Demo。

| 开场 | 展示动作 | 收尾文案 |
| --- | --- | --- |
| 明天见客户，资料还散在微信收藏里。 | 导入来源 → 查看失败与重复 → 把问题送进研究工作区。 | 先把材料找齐，再把要问的问题写清楚。 |
| 同事问：这条结论，依据是哪一版？ | 打开研报来源和版本对比 → 指出变化与缺口。 | 讨论可以从证据开始。 |
| 研报写完了，方案会议仍不知道怎么推进。 | 展示架构蓝图、依赖、风险和待验证问题。 | 带着假设、依据和下一步去开会。 |

## 商业价值怎么说

> 对方案和咨询团队，Anti-FOMO 希望减少资料查找、重复核对和研究交接的耗时。试点时，我们会用同一批公开材料，对比现有流程与产品流程的准备时间、来源覆盖和返工次数。节省多少，先测再说。

## 邀请具体反馈

> 试着用一条公开客户场景跑通“来源 → 研究 → 方案问题”。如果某个引用打不开、某次重试没恢复，或下一步建议用不上，请在 Issue 里给出脱敏输入、操作步骤、预期和实际结果。连接器、评测样本、界面和文档 PR 都欢迎。
